Map files are used to load maps from storage.
The first line represents the width and height of the map, in map sections.
The second line represents the lock Boolean values for each section. 0 is unlocked, 1 is locked.
The third line represents the map section id for each map section. 0 is a default section, 1 is an enemy spawning section.
The fourth line represents the width and height of each section, in tiles.
The fifth line begins the sections data, with an array of tile ids for each tile in each section.
